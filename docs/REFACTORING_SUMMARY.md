### 2. 目錄結構規劃

```
KeywordTools/
├── src/                      # 源代碼（未來重構）
│   ├── core/                 # 核心業務邏輯
│   ├── gui/                  # GUI 相關
│   ├── utils/                # 工具函數
│   └── models/               # 數據模型
├── data/                     # 數據文件
│   ├── keywords/            # 關鍵字文件
│   ├── reports/             # 生成的報表
│   └── samples/             # 示例數據
├── config/                   # 配置文件
├── scripts/                  # 腳本
├── tests/                    # 測試
└── docs/                     # 文檔
```

### 3. 工具腳本

#### organize_files.ps1
自動化文件整理腳本：
- 移動關鍵字文件到 `data/keywords/`
- 移動報表到 `data/reports/`
- 移動示例到 `data/samples/`
- 移動配置到 `config/`
- 移動腳本到 `scripts/`
- 刪除臨時和測試文件
